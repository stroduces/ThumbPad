# Troubleshooting

- **Cannot find computer:** same private Wi-Fi/subnet, no guest/AP client isolation. Allow the desktop executable on private networks if your firewall asks. The app does not modify firewall settings. VPNs may change the selected adapter; restart desktop after switching adapters. Use the full manual invitation if mDNS is filtered. Guest/client isolation can block manual connections too.
- **Invitation expired / pairing denied:** generate a new QR, scan it, and approve within one minute. Copy the whole manual URI including fingerprint/secret; a six-character code alone is not enough. Never approve an unfamiliar phone.
- **Certificate fingerprint changed:** fail closed. Verify you are pairing to your own desktop, forget the old connection and scan the new invitation. Do not disable certificate validation.
- **Saved computer no longer connects after DHCP changes:** generate/scan a fresh desktop invitation. Automatic discovered-address substitution is intentionally not used as trust evidence. Certificate identity is retained across ordinary app upgrades.
- **macOS cursor does not move:** enable Accessibility for the installed copy in Applications, then relaunch. Remove obsolete permission entries only through System Settings if you choose to. Approve Local Network permission when prompted. The app cannot operate on every protected system surface.
- **Windows cursor does not affect elevated apps:** SendInput is subject to Windows integrity restrictions. Use normally running applications; ThumbPad does not silently elevate itself. Secure desktop/lock-screen control is unsupported.
- **Drag appears held after phone sleeps:** host heartbeat timeout releases all held buttons after three seconds. Disconnect/disable in the tray provides a faster explicit release. Force-killing the desktop process while a button is held cannot guarantee a final native up event; resume the companion and release using a physical mouse if required.
- **App pauses during a call / switches away:** phone disconnects safely, clears drag, and reconnects the selected saved computer when brought back in the same process. Android may kill the process; select a saved computer after a cold start. No background mouse-control service runs.
- **Palm rejection blocks deliberate touch:** turn it off in settings. It uses touch-size heuristics; devices report contact areas differently. The precise toggle helps small controls without requiring pressure.
- **Scrolling feels backward / too fast:** change natural scrolling or speed. Dedicated side-strip scroll works with one thumb. Horizontal scrolling is optional. Windows wheel scaling is approximated from logical pixels; not every application supports equally smooth scrolling.
- **Keychain / Credential Manager unavailable:** startup fails closed. Do not delete the vault to hide a decryption error. Restore the OS secure store or deliberately reset/re-pair after backing up your data. A second simultaneously running copy can collide on the listener; quit the other copy.
- **APK installation blocked:** use the signed debug APK or sign the release. An unsigned APK cannot install. A release signed by a different key cannot replace debug without uninstalling it first. Samsung policy/work profiles may prohibit sideloading; follow the device owner's policy.
- **macOS build missing:** run the workflow on GitHub or `scripts/release.ps1 -Target macos` on a Mac. Windows cannot create a real Apple app/DMG. No placeholder DMG is included.
